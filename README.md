# Streamer

Streamer plays the videos on your Mac on your TV – Apple TV and AirPlay TVs, Google Cast devices, DLNA smart TVs, or on the Mac itself – in any format, with subtitles in your own language.

- [Support](https://erik-rise.github.io/StreamerApp/support.html)
- [Privacy Policy](https://erik-rise.github.io/StreamerApp/privacy.html)

Found a bug or have an idea? [Open an issue](https://github.com/erik-rise/StreamerApp/issues/new). You can also use **Help → Report a Problem…** in the app, or email dev@rise.se.

This repository holds the app's public web pages and issue tracker; the app's source code is not public.
